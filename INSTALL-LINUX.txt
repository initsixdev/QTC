QTC TERMINAL 1.0.0 - LINUX INSTALLATION

1. Make the standalone binary executable:

   chmod +x qtc-linux-x86_64

2. Test without a radio:

   ./qtc-linux-x86_64 --demo

3. Install for the current machine:

   sudo install -m 0755 qtc-linux-x86_64 /usr/local/bin/qtc

4. Run with automatic serial detection:

   qtc

5. Or force a device:

   qtc --device /dev/ttyACM0

USB ACCESS

List candidates:

   qtc --list-devices

On many Fedora, Debian, and Ubuntu systems, add the user to dialout:

   sudo usermod -aG dialout "$USER"

Then log out completely and log in again.

Optional desktop-oriented udev rule:

   qtc --print-udev-rule | sudo tee /etc/udev/rules.d/99-qtc-meshcore.rules
   sudo udevadm control --reload-rules
   sudo udevadm trigger

Unplug and reconnect the radio.

RUNTIME LIBRARY

QTC dynamically links SQLite 3.

Fedora:

   sudo dnf install sqlite-libs

Debian or Ubuntu:

   sudo apt install libsqlite3-0

Arch Linux:

   sudo pacman -S sqlite

OPTIONAL NOTIFICATIONS AND SOUND

Fedora:

   sudo dnf install libnotify pipewire-utils

Debian or Ubuntu:

   sudo apt install libnotify-bin pipewire-bin

Arch Linux:

   sudo pacman -S libnotify pipewire-audio

QTC continues receiving and storing messages when optional helpers are absent.

CORE LIFECYCLE

Ctrl+C or F8:
   detach this terminal; leave the background core and USB connection running

Ctrl+Q twice:
   stop the background core and release USB

Commands:

   qtc status
   qtc shutdown

PROFILES

   qtc --profile home --device /dev/ttyACM0
   qtc --profile field --device /dev/ttyACM1

Back up an existing 2.3.1 database before first use with real hardware.

RESTORED MESSAGE AND DEVICE CONTROLS

F2 or e:
   edit the selected contact alias

g:
   assign the selected contact to a favorite group

Page Up / Page Down:
   scroll conversation history

F4 Settings:
   notification and sound controls, themes, retries, radio name, TX power,
   local/flood advertisement, forced stored-message sync, and USB reconnect

F5:
   reconnect the USB radio through the persistent background core
